# Kahve Fincanı Dans Eden Algoritma

## Bilimsel Bir Başka Devrim

Bu repository, kahve fincanlarının neden dans etmediği sorusuna cevap verir. Cevap: Çünkü daha önce kimse bu algoritmayı yazmamıştı.

Kafein moleküllerinin titreşim frekansını hesaplayarak, terminalde bir ☕ emojisini dans ettirir. Bu, yapay zeka, kuantum bilgisayarlar ve kahve kültürünün zirvesidir.

### Nasıl Çalıştırılır?

```bash
python dans.py
```

**Uyarı:** Dans sırasında kahveniz dökülebilir. Sorumluluk kabul edilmez. Çay içenler bu repoya bakmasın.

### Özellikler

- Gerçekten dans eden bir fincan (emoji)
- Rastgele hareketler
- Bilimsel görünen yorumlar
- Türkçe ve emoji destekli
